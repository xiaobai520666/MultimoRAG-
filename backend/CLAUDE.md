# 后端模块 — backend

## 模块功能

FastAPI 后端，提供 RAG 系统的全部 API 接口和业务逻辑。负责文件解析、向量嵌入、知识检索、对话编排和 Agent 工具执行。

## 需求边界

**属于本模块：**
- 所有 API 接口的定义与实现
- 文件上传、解析（文本/OCR/音频转写）
- 分块与向量嵌入
- 向量存储与检索
- 对话上下文组装与 LLM 调用
- Agent 工具注册与执行
- 模型 API 适配（千问等）
- 元数据与对话持久化

**不属于本模块：**
- 前端界面渲染
- 浏览器端交互逻辑
- 第三方 API 的认证与鉴权（只适配调用）

## 接口定义

见 `api/CLAUDE.md` 和 `README.md` 中的 API 概览。

所有后端接口前缀：`/api/v1/`

返回统一格式：
```json
{
  "code": 0,
  "data": {},
  "message": "ok"
}
```

## 依赖与约束

- Python 3.11+
- FastAPI
- Qdrant（向量存储）
- PostgreSQL（元数据）
- 千问 API（LLM/嵌入/OCR/音频）
- 运行环境：Docker 容器 / 本地虚拟环境
